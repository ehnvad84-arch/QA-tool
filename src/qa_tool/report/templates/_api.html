Как читать. Родной API — собственный интерфейс производителя (у Hikvision — ISAPI, у Dahua — CGI), через него работает веб-интерфейс камеры. ONVIF — общий стандарт, через него камеру видят регистраторы и программы видеонаблюдения. Одна и та же настройка есть в обоих; пара — «настройка ONVIF ↔ параметр родного API» и правило перевода шкалы. Расхождение значит, что камера сообщает одно и то же по-разному: один из ответов неверен, и регистратор по ONVIF увидит не то, что показывает веб-интерфейс.
