Как читать. Раздел — один ресурс родного API (адрес ISAPI, имя конфигурации CGI). Тип: «число 0…100», «список: …», «текст до 32 знаков»; «только чтение» — камера не даёт его менять; «не объявлены» — камера не сообщила допустимые значения. [*] — параметр повторяется по каналам, профилям или потокам с одинаковыми допустимыми значениями; текущие значения — по индексам «[0] 50 · [1] 50». «скрыто» — пароль, ключ или токен: значение вырезано. «только описание» — раздел сети, учётных записей или безопасности: значения не читались и не сохранялись. «меняется сам» — значение менялось без записи (автоматика, счётчики).
