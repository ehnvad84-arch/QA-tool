# Прогон

Прогон проверяет все камеры стенда по сценарию. Надпись над плитками показывает текущую фазу.

<!-- help: run-start -->
## Начать прогон

Запускает проверки на всех камерах одновременно. Перед стартом программа берёт пароли камер из хранилища. Если пароля нет, прогон не начнётся и программа назовёт место.

<!-- help: run-stop -->
## Остановить

Начатые проверки дорабатывают, неначатые отмечаются «пропущена: прогон остановлен». Протоколы выпускаются по сделанному.

<!-- help: run-tiles -->
## Плитки мест

Каждая плитка — одно место: камера, текущая проверка, счётчики и полоса прогресса.

- **прошла** — камера сделала то, что ожидалось;
- **не прошла** — дефект камеры, попадает в задачи программистам;
- **пропущена** — проверку не запускали (сценарий, место стенда, остановка);
- **ошибка стенда** — проверку не удалось довести до конца (пропала связь, проверка зависла). Это не дефект камеры, в задачи не попадает.

Если камера перестала отвечать **во время** проверки, эта проверка — «не прошла»: это сбой камеры или прошивки, он попадает в задачи программистам. Оставшиеся проверки этой камеры получают «ошибка стенда: нет связи», остальные камеры продолжают.

Неверный логин или пароль камеры — «ошибка стенда»: поправьте их на экране «Камеры».
