# Испытания на стенде

Короткий порядок для первых испытаний версии 0.2.

## Что проверяет эта версия

Связь с камерой и паспорт, тесты ONVIF, профили S, G, M, T, видеопоток H.264 и H.265, запись на карту и выдача архива (если камера их объявляет), протоколы PDF, Excel и HTML с задачами программистам.

Пока не проверяются: API производителя, веб-интерфейс, картинка и кодеки, оборудование стенда (реле, звук, свет). Выдача архива на настоящей камере ещё не подтверждена: её результаты смотрите особенно внимательно.

## Установка

- **Windows:** запустите `*-setup.exe`. Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» и «Выполнить в любом случае»: программа не подписана.
- **Linux:** сделайте файл `*.AppImage` исполняемым (свойства файла или `chmod +x`) и запустите.

Компьютер должен быть в одной сети с камерами.

## Порядок работы

1. **Стенд:** выберите сетевую карту к камерам и папку прогонов.
2. **Камеры:** нажмите «Найти камеры» или добавьте вручную. Укажите логин и пароль. Не ошибайтесь в пароле: после нескольких неверных попыток камера может заблокировать вход.
3. **Сценарий:** оставьте всё как есть. «Изменяющие» и «разрушающие» проверки выключены: для первых испытаний камера ничего не меняет.
4. **Прогон:** нажмите «Начать прогон» в левой колонке и следите за местами.
5. **Протоколы:** откройте протокол каждой камеры.

Сетевые настройки, логины и пароли камер программа не меняет никогда.

## Что прислать после испытания

Папку прогона целиком (`QA-…` в папке прогонов) и несколько слов: какая камера, что ожидали, что показалось неверным. В папке нет паролей, но есть сведения о камере и ответы камеры.

Если программа не запускается, пришлите снимок ошибки и вывод команды `qa-tool doctor` (в Windows — `qa-tool-cli.exe doctor` из папки программы).
