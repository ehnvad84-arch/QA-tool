# API камер «Рувер»

Проверка «API «Рувер»» идёт только у камер, для которых на экране «Камеры» выбран производитель `ruver`. Камеры других производителей проверяются ONVIF и остальными общими модулями, строк API у них нет.

Программа входит в камеру один раз и закрывает сеанс в конце, в том числе при остановке и сбое. Камера держит не больше трёх сеансов, а неверный пароль расходует попытки входа, поэтому после отказа в пароле программа не пробует снова.

В протоколе — строка на каждую операцию API:

- **Чтение** — идёт всегда. «Прошла» значит, что камера ответила кодом 200 и ответ совпал с описанием API. Операции, которой нет в этой прошивке, ставится «пропущена», а не задача программистам.
- **Запись** — только с галочкой «изменяющие». Программа меняет настройку на другое допустимое значение, читает его, возвращает исходное и сверяет. Значение вне пределов камера должна отклонить: это отдельная строка с окончанием `-LIMIT`. В конце строка «Сверка настроек» сравнивает все настройки с тем, что было до записи. Если что-то не вернулось, в причине стоит «камера осталась изменённой»: такую камеру нужно проверить вручную.
- **Разрушающие** — только с галочкой «разрушающие»: перезагрузка и подготовка SD-карты. Удаление записей программа не вызывает, пока ей не задано, что удалять.
- **Запрещено табу** — сеть, учётные записи, NTP и источник времени, мультикаст, сброс и импорт настроек. Эти операции не отправляются никогда, ни с какой галочкой.
- **Не вызывается** — операции, которые нельзя вернуть как было: движение объектива, события, туры, пресеты, сброс параметров. Причина указана в строке.

Настройка, которой нужна перезагрузка, не меняется: строка «пропущена: применяется после перезагрузки».

Ответы, в которых могут быть секреты (конфигурация, пользователи, журнал, экспорт настроек), и двоичные ответы в доказательства попадают только как размер и хеш.

Если подошёл предел времени или прогон остановлен, новые значения не пишутся, а уже записанное возвращается и сверяется. Поэтому остановка может занять несколько секунд.
