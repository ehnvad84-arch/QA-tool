Камеры подключают примерно через сутки после 08.11. До подключения работа идёт на виртуальных камерах. Этот план — порядок на день подключения, чтобы не тратить время камер на подготовку.

## До подключения

1. Сборка с ветки `feature/web` (там этапы 2–5): `doctor` проходит, браузер внутри.
2. Пароли — из таблицы директора 07.11. Каждый пароль брать только из строки своей камеры и сверять IP до запуска (never.md, 05.11).

5. Если камеры снова через туннель — заполнить `lan_address` у каждой (иначе условие безопасности С2 не выполнено). Поток через туннель искажён: замеры потока только в сети камер.
