### Попытки входа при неверном пароле

Измерено на заглушке, полный прогон через `Runner`:

| Случай | Отклонённых входов | Итог |
|---|---|---|
| неверный пароль, часы верны, `ter:NotAuthorized` | 1 | ошибка стенда, остальное пропущено |
| неверный пароль, часы +3600 с, `wsse:FailedAuthentication` | 2 | ошибка стенда, остальное пропущено |
| неверный пароль, HTTP 401 с разбираемой страницей | **11** | 8 ложных задач (находка 27) |

Повтор ограничен: один раз на процесс камеры и только при новой поправке больше 5 с. Рекурсии нет. Рабочий процесс — spawn, все проверки камеры идут в нём, поэтому поправка живёт весь прогон и не наследуется от окна.

### Непокрытые случаи — для test-writer

1. HTTP 401 с правильно оформленной страницей HTML, XHTML или с Fault SOAP 1.1 через `SoapClient` и CORE-CONNECT-1. Сейчас заглушка отдаёт только `b"Unauthorized"`, а `test_only_codes_decide_that_credentials_were_rejected` создаёт исключение руками, поэтому находка 27 в тесты не попала.

7. Сбой прогона посреди проверок: точки и строки хода на экране.
8. Снятие галочки модуля с CORE-CONNECT-1.
9. Задачи одной важности из разных модулей и фаз: окно и протокол в одном порядке.
