## 04.11 — CI на Windows: 4 теста перезагрузки и 1 ч 20 мин

Этап 3 упал на Windows дважды (a6d2088, 113c59a), сборки не запускались. Причина одна: httpx.request заново читал сертификаты на каждый запрос (на Linux 21 мс, на Windows по времени прогона около 0,15 с), а простой тестовой камеры длился 0,15 с, и опрос его не заставал. Логика проверки ни при чём: настоящая камера лежит от 3 с. Воспроизведено на Linux задержкой 0,2 с на запрос: старый код — 4 падения, новый — 4 прохода. Контекст TLS теперь один на процесс (1,6 мс на клиент), простой mock считается запросами, а не временем.
