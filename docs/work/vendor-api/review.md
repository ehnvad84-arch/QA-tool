## Проверка по пунктам задания

1. **Табу — подтверждено, замечаний нет.** Исключение входа: 13 попыток обхода (`;`, `..`, `%2f`, `#`, `?`, `\`, `//`, другой метод) не дали пропуска к другому адресу. Единственное срабатывание — `lo\tgin`: `urlsplit` убирает табуляцию, но адрес остаётся адресом входа, обхода нет. `check_http` исключение не ослабляет. Каждый запрос чтения и записи со всеми значениями из карты и телом `need_reboot` проходит табу, каждая операция вида «табу» им отказана. `_check_allowed` не пропускает «табу» и «не вызывается». Карта согласована с генератором.
2. **Возврат — есть blocker,** находки 1–4, 6, 8. Смещение блока №1 на основном потоке программа сообщает, но вернуть не может, а ложная строка от порядка блоков неотличима от настоящей.
3. **Пароль и секреты — закрытые ответы чисты.** В схемах открытых адресов полей с секретами нет. `schema_errors` для закрытых ответов значений не выносит (проверено). Остаток — находка 11.
4. **Сеанс — обычный ход в порядке.** Один сеанс, закрытие при любом исходе, одна попытка при отказе, один повторный вход. Слабые места: находки 1 и 10.
5. **Планировщик — в порядке, остаток minor.** `timeout_s` = 900 + 300 + 180 = 1380 с выше предела 1200 с. `Runner.stop()` только ставит событие и ждёт `phase_done`, процесс снимается лишь по `timeout_s`. Остаток — находка 12.
6. **Сборка — по чтению в порядке, не запускалась.** `collect_data_files("qa_tool")` забирает `data/`, `MAP_FILE` указывает на `qa_tool/data`. `jsonschema` есть в `pyproject.toml` и `uv.lock`. В карте нет `description` и `example`. Нужна проверка: хуки `jsonschema` в сборке подтвердит только CI (`build-linux`, `build-windows`); группа build в `.venv` не установлена. Остатки — находки 14 и 15.
