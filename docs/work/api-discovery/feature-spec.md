## Зачем — главная сессия

Родной API чужих камер (Hikvision ISAPI, Dahua CGI/RPC2, Tiandy, Beward) программисты сейчас разбирают руками по веб-интерфейсу, PDF вендоров и трафику браузера — часы и дни на модель (директор 09.11). Нужна карта родного API каждой подключённой камеры (разделы, параметры, допустимые значения, текущие значения) и сверка с ONVIF: одна и та же настройка в родном API и в ONVIF читается одинаково, иначе — задача программистам (живой случай 09.11: Hikvision .111 — ONVIF Exposure AUTO, ISAPI ExposureType manual; ONVIF MaxGain = ISAPI GainLevel). Таблица соответствий «ONVIF ↔ родной параметр» строится программой сама (директор 09.11, вариант C), для всех брендов стенда сразу. Карты копятся «на будущее»: на них потом встанут сравнение прошивок и адаптеры производителей (AD-4).

## Решения — главная сессия

| Вопрос | Выбрано | Почему | Отвергнуто |
|---|---|---|---|
| Как узнаём родной API сейчас (директор 09.11) | руками по вебу, PDF и трафику браузера — часы и дни на модель | боль настоящая, а не «на всякий случай» | — |
| Минимальная версия (директор 09.11) | карта API + сверка с ONVIF: расхождение — строка «не прошла» с задачей | ловит то, что ONVIF скрывает (.111 09.11) | только карта; карта + сравнение прошивок; заготовка адаптера |
| Охват брендов (директор 09.11) | все бренды стенда сразу: Hikvision, Dahua, Ruware, Tiandy, Beward | сравнивать камеры разных производителей нужно одинаково (AD-4) | сначала Hikvision и Dahua |
| Решение (директор 09.11) | вариант C — таблица соответствий ищется автоматически: программа меняет настройку по ONVIF (с галочкой «изменяющие») и смотрит, какой родной параметр сдвинулся; ручная таблица — подтверждение; основа — модель карты и сборщики в адаптерах бренда (вариант B) | без ручной работы по брендам без документации (Tiandy, Beward) | A — одна проверка со встроенными сборщиками; B — сборщики и ручные таблицы в адаптерах без автопоиска |
| Допущения брейншторма (директор 09.11) | приняты 1–7 с поправкой: таблица соответствий — для всех брендов; сравнение прошивок и заготовки адаптеров — вне рамок первой версии | — | — |
