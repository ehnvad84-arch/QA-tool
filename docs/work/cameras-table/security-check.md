## Проектные правила (docs/rules/security.md, never.md)

- [x] Табу (AD-7): экран «Камеры» к камере не обращается. Правится только то, с чем программа входит в камеру (stand.yaml и keyring). Новых клиентов к камере нет, `core/taboo.py` не затронут.
- [x] Пароли только в keyring. Строка таблицы держит пароль в памяти экрана. На стенд он уходит только через `set_password`; `save_stand` записывает поля без пароля. Тест S2 проверяет, что пароля нет в stand.yaml.
- [x] Пароль открыт на экране — решение директора 20.11, записано в спеке. Рекомендация: добавить одну строку в «Принятые риски» security.md (снимки экрана и показ экрана раскрывают пароли всех камер на местах).
- [x] Пароли и токены вырезаются в протоколах. Markdown строится из той же модели `Protocol`, что и HTML: `redact` в `build_protocol`, `scrub` известного пароля в `run_check`. Тест `test_markdown_protocol_escapes_camera_answers_and_hides_secrets` подтверждает.
- [x] Ответы камер экранируются. HTML без изменений. В Markdown `finalize=md_text` экранирует обратную косую черту, обратную кавычку, `*`, `_`, `[`, `]`, `|`, `#`, а также `<` и `>`, переносы заменяет на `<br>`. Названия камер на плитках и в прогоне выводятся как PlainText. Остаток — minor-находка 7 (автоссылки GFM, `~`).
- [x] Пути файлов: имя .md собирается из `stem` списка документов прогона и `_PROTOCOL.fullmatch` (только цифры). Данных камеры в путях нет.
- [x] Адреса: работа только с адресами из списка стенда. Правка «Адреса» в таблице меняет сам список стенда (инженер), сканирования сети нет.
