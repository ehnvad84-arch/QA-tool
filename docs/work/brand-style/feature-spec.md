# Спецификация: brand-style

Статус: утверждена (просьба директора 2026-11-21: «ПО делай в фирменном стиле», брендбук «фирм стиль рувер.pdf»)
PRD: docs/PRD.md → окно программы и протоколы

## Зачем — главная сессия

Программа — инструмент компании «Рувер»; окно, значок и протоколы должны выглядеть по брендбуку: логотип `<РУВЕР>`, знак `<Р>`, шрифт Montserrat (Bold — заголовки, Medium — подзаголовки, Regular — текст), цвета red #BA0000 (акцент, заголовки), black, white, dark grey #D8D8D8 (плашки), grey #F2F2F2 (фон).

## Поведение (BDD) — главная сессия

### S1: окно в фирменном стиле
- **Дано** светлая тема (по умолчанию)
- **Тогда** фон #F2F2F2, меню белое с логотипом «Рувер» сверху, выбранный пункт и главная кнопка — красные с белым текстом, заголовки экранов красные, шрифт Montserrat

### S2: тёмная тема
- **Тогда** логотип с белыми частями вместо чёрных, акцент светло-красный (#FF5C5C: фирменный на тёмном фоне не читается), контраст текста не ниже 4.5:1

### S3: значок программы и установщика
- **Тогда** знак `<Р>` на светло-сером скруглённом квадрате — в окне, панели задач и установщике

### S4: протоколы
- **Тогда** HTML и PDF протокола: шрифт Montserrat (если есть), заголовок красный, шапки таблиц серые #D8D8D8

## Вне рамок — главная сессия

- Картинки мастера установки Inno Setup — пока только значок.
- Цвета состояний (прошла — зелёный, ошибка стенда — янтарный) остаются смысловыми, не фирменными.
- Логотип в протоколе — нет: протокол — документ ОТК о любой камере.

## UI — ui-designer

Токены — `gui/theme.py` (LIGHT/DARK). Логотип — `gui/images/ruver-logo.png` (светлая), `ruver-logo-dark.png` (тёмная), знак — `ruver-sign.png`; вырезаны из векторного брендбука в 600 dpi с прозрачным фоном. Кегль окна 13 px (Montserrat шире PT Sans).

## Архитектура, API и данные — backend-architect

`theme.py`: палитры, `logo()`, `draw_icon()`, `app_icon()`; `main_window.BrandLogo` рисует логотип по текущей теме; `app.create_app` ставит значок окна; `packaging/make_icon.py` берёт `draw_icon`. Шрифты: Montserrat Regular/Medium/Bold (OFL 1.1) вместо PT Sans, PT Mono остаётся для времени.

## Безопасность — backend-architect

—: только оформление. Шрифты — OFL 1.1 (лицензия рядом, NOTICE), логотип — собственность «Рувер», из брендбука, переданного директором.

## Решения — главная сессия

| Вопрос | Выбрано | Почему | Отвергнуто |
|---|---|---|---|
| Акцент тёмной темы | #FF5C5C | #BA0000 на тёмном — контраст 2.9 | фирменный как есть |
| Статусы | смысловые цвета | красный «не прошла» уже фирменный; зелёный/янтарный нужны для различения | всё в красно-серой гамме |
