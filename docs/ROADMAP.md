| № | Этап | slug | Результат | Статус |

| 0 | Постановка | — | PRD, правила, перечень стенда, репозиторий | готово 2026-11-03 |

| 2 | ONVIF + архив | `onvif` | onvif-tt в наш формат, матрица профилей по testspecs, проигрывание архива G, метаданные M, SD-карта | идёт |
| 3 | Адаптеры API производителей | `vendor-api` | механизм адаптеров; первый — «Рувер» (OpenAPI): все операции, «записал → прочитал», восстановление настроек | — |
